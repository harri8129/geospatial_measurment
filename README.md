# Geospatial File Measurement API

A FastAPI-based backend service for processing geospatial files and calculating
measurements such as polygon area and line length.

## Tech Stack

- Python
- FastAPI
- PostgreSQL
- GeoPandas
- Shapely
- PyProj
- Redis
- Docker

## Current Status

Phase 0 - Project Bootstrap

The initial FastAPI application and modular project structure have been created.
